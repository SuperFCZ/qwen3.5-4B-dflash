# Frozen Draft analysis-v3

From the repo root run `python3 -B framework/custom_ops/draft_a_core_scheduler_profile_v3/analyze_v3.py --root /home/w00949577/qwen35-dflash-run/a-only-draft-profile-OC8pCW`. This offline tool creates **only a fresh analysis-v3/**; an existing directory is never overwritten. Requires v2 plus its original profile, admission, scheduler Source/Projection Smoke/Export and deployment records at their bound paths. No ATC, msprof, Runner or accelerator calls. Failure preserves traceback.txt.

Read summary-v3.md first, then notify-wait-analysis.md, group-quant-projection-analysis.md, head-matmul-analysis.md and attention-analysis.md. Under c16/ and c64/, JSON files retain the full detail hidden in the compact Markdown, including descriptors, CSV line references, graph edges and all wait intervals. Raw notify CSV rows (including rows with no corresponding timeline occurrence) are preserved separately. The two sources are not added together. stream/task IDs can recur across executions, so ambiguous joins have no claimed individual CSV fields. A raw field absent from the timeline is null, not filled from a guessed occurrence.

A wait's named temporal neighbors on the same PID are not necessarily its producer/consumer. Raw start/end are absolute trace microseconds; ordering/overlaps use Decimal. The held time, the union of held intervals, and its intersection with the union of enclosed GroupQuant tasks are distinct measures. Per-wait overlap can include events outside the v2 call assignment and is not summed as an exclusive phase. All 38 host windows are retained; summaries use 7–36. Wait object and causal critical path remain unresolved without stronger dependency evidence.

Projection identity uses a named immutable node record from the compiled graph deployment and the NZ weight/scale hashes of accepted single-projection inputs. Unique logical shapes may identify a projection role without identifying its layer. The numeric suffix is never a mapping rule. Times are reported as device task durations (nearest-rank P95); weight bytes are INT8 and FP16 Group128 scales for that shape. Head analysis distinguishes a weight-input conversion from output-side neighbors. A TopK path alone is not proof of K=1. Attention requires data edges rather than control edges: MatMul→Softmax→MatMul is structural evidence; same-layer Q/KV projection ancestry on different operands is stronger evidence. Unsupported/fused edges or missing descriptors are not invented.

The v2 strict status is carried separately. Timed task membership here is PROVISIONAL_HOST_ENCLOSURE. Neither task sums nor overlapping waits measure removable Draft wall time. Any new device experiment is a recommendation only.

Tests: `python3 -B -m unittest discover -s framework/custom_ops/draft_a_core_scheduler_profile_v3/test -v`. Fixtures require no server data.
