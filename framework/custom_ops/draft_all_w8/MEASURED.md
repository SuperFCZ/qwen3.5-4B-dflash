计时从已加载模型的 Execute 开始，到该次完整 Draft 输出的 stream sync 结束，包含 C64 FC 的图内激活重排。每档三轮交错正反序，每轮每边 5 次预热、30 次正式调用，共 90 个正式样本。两档中位数分别距 13.33 ms 目标 0.271305 和 0.634895 ms。

每档实际 OM 均核验 26/26 个预期执行段、52 份打包权重与 Scale、各自实测的 Cube 计划及 8-block 调度。全 W8 与对照各自的 15 个 token ID 及十份完整 KV 均与封存参考逐位相同。Runner 检查两种输出 poison、Guard、Readonly、Repeat、设备同步及实际加载的 DSO。
